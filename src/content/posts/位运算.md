## 优先级

| 运算符       | 优先级 |
|:---------:|:---:|
| （）        | 1   |
| ! ~       | 2   |
| * / %     | 3   |
| + -       | 4   |
| << >>     | 5   |
| < <= >= > | 6   |
| &         | 7   |
| ^         | 8   |
| or         | 9   |

## 特殊用法

+ 取反(~)改变符号位 取反保持正负性需加负号 ~-a or -~a
  
+ a ^ a = 0
+ a ^ 0 = a
+ a ^ -1 = ~a
+ 交换a,b的值： a ^= b ^= a ^= b
